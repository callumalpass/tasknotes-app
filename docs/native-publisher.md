# Retired native web publisher

The `release/native-*` publisher, protected manual hash packet intake and its
staging deployment path are retired. They are not release alternatives.
See [web deployment](deployment.md) for the shared exact-source App CD route.

Historical public packets remain only as immutable regression fixtures, not
publisher authority. No trust roots, policy keys, app identity or signing
identities changed. Mobile store workflows are independent and unchanged.
